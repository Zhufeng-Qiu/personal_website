`Java` `Spring Boot` `Spring MVC` `Spring Security` `JPA` `AWS` &nbsp;·&nbsp; Jan.–Apr. 2023

A student and course management platform built on the Spring framework.

Application architecture in Spring MVC, persistence through Spring JDBC and
Spring Data JPA, access control and authentication with Spring Security, and
runtime monitoring via Spring Boot Actuator. Deployed to AWS Elastic
Beanstalk.
