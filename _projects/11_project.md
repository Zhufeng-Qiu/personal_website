`React` `Redux` `Node.js` `Express` `MongoDB` `Sass` &nbsp;·&nbsp; Feb.–Dec. 2023

A full-stack social platform for developers: authentication, profiles, and forum
posts.

RESTful APIs on Node.js and Express, with Mongoose ODM against a MongoDB cloud
database. Routes are protected with JWT and express-validator middleware.
Application state is managed with Redux reducers and actions; the UI is React
with Sass. Deployed to Heroku.
