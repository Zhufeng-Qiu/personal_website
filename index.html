Lab 02 · Moving LLM state
From the project BoundRelayAug–Sep 2026→

Fewer bytes
≠ less time.

One 3× smaller KV cache is slower between two GPUs and faster on a durable write. Same cache, same codec; the path sets the sign.

Race raw against compressed →
Recorded · one 234.9 MB KV cache · 3.02× fewer bytes

GPU → GPU · 7-stage pipeline

raw · 22.19 ms
compressed · 43.65 ms

Durable write · MooseFS fsync

raw · 563.1 ms
compressed · 354.6 ms
1.97×slower compressed, GPU → GPU1.59×faster compressed, durable write

Each path is scaled to its slower arm. In the paired round, no 95% interval crosses 1.
